# FlairOS image assets

Place custom BMP assets here for the desktop and boot artwork.

- `BOOT.BMP`: optional boot artwork.
- `WALL.BMP`: optional desktop wallpaper. Without it the built-in dusk wallpaper is drawn.
- `CURSOR.BMP`: optional arrow cursor, up to 32x32 pixels. Pure magenta (`#FF00FF`) is
  transparent and the hotspot is the top-left pixel. Without it (or if the file is invalid)
  the built-in arrow is used. The pointing hand and text I-beam are always built in.
- Additional BMP files can be used by components that load assets through the
  shared image subsystem and AirGraph.

Supported BMP input is uncompressed BI_RGB, 24-bit or 32-bit, with either
bottom-up or top-down row order. The shared decoder is in
`include/image.h` / `kernel/image.c`; AirGraph's `ag_draw_image()` draws a
decoded image using its normal clipping and blit path.

Decoded output is packed `0x00RRGGBB`. Callers provide the destination buffer;
the decoder validates dimensions, pitch, and capacity and does not allocate
memory internally.

## Built-in Material icon pack

The icons/ folder contains original 64x64, anti-aliased, 24-bit BMP icons generated by tools/generate-bmp-icons.py:

- home.BMP, clock.BMP, terminal.BMP
- folder.BMP, settings.BMP, battery.BMP
- document.BMP, image.BMP

The generator is deterministic and uses only Python's standard library. The icon pack is kept as external resources rather than linked into the low-memory i386 kernel image; embedding all eight full-resolution BMPs exceeds the reserved kernel/BSS memory layout. Current desktop shell icons are drawn with AirGraph vector primitives. A userland image-drawing API is a prerequisite for Explorer to render these BMP assets directly.

Internet access

FlareOS uses v86's NE2000 virtual Ethernet card with the Wisp WebSocket protocol. The hosted relay provides outbound TCP connectivity for web traffic without requiring a VPN or a local network adapter.

  1. Paste the OpenFiddles Wisp address below.
  2. Choose Save & restart to reconnect the virtual network.
  3. Inside FlareOS, test with ping 1.1.1.1 or open a TCP-based web client.

Wisp supports outbound TCP web traffic on ports 80 and 443. Arbitrary UDP, inbound connections, and access to private networks are intentionally disabled. Leave blank to use the isolated in-browser network. The relay URL is saved only in this browser.

Press Ctrl+Alt+D to switch between the desktop and text mode. In the desktop Terminal, try help, time, uptime, net, or ping 1.1.1.1.
